# Offline Bundles

This directory is the destination for **air-gapped / offline image bundles**
created by `make bundle`.  No bundle files are committed to git; they are
generated locally and distributed via Nexus, S3, or physical media.

---

## Creating a bundle

```bash
# Build all images first
make build-all REGISTRY=registry.internal/security-platform TAG=1.2.3

# Create a tar archive containing all images
make bundle REGISTRY=registry.internal/security-platform TAG=1.2.3

# Output: offline-bundles/out/spt-bundle-1.2.3.tar
#         offline-bundles/out/spt-bundle-1.2.3.tar.sha256
```

The bundle target calls `docker save` for every image and writes:

| File | Description |
|------|-------------|
| `out/spt-bundle-<TAG>.tar` | Compressed Docker image archive |
| `out/spt-bundle-<TAG>.tar.sha256` | SHA-256 checksum for integrity verification |

---

## Restoring a bundle (air-gapped host)

```bash
# 1. Verify integrity
sha256sum -c spt-bundle-1.2.3.tar.sha256

# 2. Load all images into the local Docker daemon
docker load -i spt-bundle-1.2.3.tar

# 3. Confirm images are available
docker images | grep spt-
```

---

## Pushing to an internal registry after restore

```bash
INTERNAL_REGISTRY=registry.internal.example.com:5000

for img in base c-cpp-analysis fuzzing gitnexus semgrep codeql sbom secrets corpus-tools replay-runner symbolic; do
    docker tag registry.internal/security-platform/spt-${img}:1.2.3 \
               ${INTERNAL_REGISTRY}/spt-${img}:1.2.3
    docker push ${INTERNAL_REGISTRY}/spt-${img}:1.2.3
done
```

```

├── README.md        ← this file

    ├── spt-bundle-<TAG>.tar
    └── spt-bundle-<TAG>.tar.sha256
```
